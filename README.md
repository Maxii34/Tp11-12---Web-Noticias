# 📰 Buscador de Noticias

Un proyecto interactivo que permite buscar noticias en tiempo real por categoría y país, utilizando una API externa. Ideal para practicar manejo de estado, consumo de APIs y maquetado responsivo.

---

## 📝 Descripción

Este proyecto es un buscador de noticias desarrollado con **React** y **React Bootstrap**, que consume la API de [newsdata.io](https://newsdata.io) para mostrar artículos según la categoría y el país seleccionado.

### Características principales:
- 🔍 Búsqueda por categoría (Negocios, Deportes, Tecnología, etc.)
- 🌍 Selección de país (Argentina, España, México, etc.)
- 🖱️ Interfaz interactiva con hover efectos y animaciones suaves
- 📱 Diseño completamente responsivo
- 🎨 Tarjetas con truncado de texto para evitar desbordes
- 🚀 Desplegado en Netlify con manejo de rutas correctas

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|----------|-----|
| **React** | Componentes y manejo de estado |
| **Vite** | Entorno de desarrollo rápido |
| **React Bootstrap** | Estilos y componentes reutilizables |
| **newsdata.io API** | Fuente de noticias en español |
| **CSS3** | Estilos personalizados y efectos |
| **Netlify** | Despliegue y manejo de rutas SPA |
